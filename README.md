
Orbit Gadgets is a tech and security hardware e-commerce web application built with Next.js (App Router), TypeScript, and Prisma ORM with a PostgreSQL database layer. 

The project features a clean component architecture, parameterized API endpoints with error handling, secure password hashing using bcryptjs, and atomic transaction processing for cart checkouts.


Tech Stack

Framework: Next.js (TypeScript, App Router)
Styling: Tailwind CSS
Database & ORM: PostgreSQL & Prisma ORM v7
Database Driver: @prisma/adapter-pg
Authentication Security: bcryptjs for salted password hashing
